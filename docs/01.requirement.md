# 需求

## 概述

该系统是一个基于文件系统，支持多域名的知识类网站加载工具，取名“Site Hangar”，寓意同一框架可容纳多个不同站点。


## 特征

+ 展示与数据分离：本系统只负责将特定文件夹下的属于以网页的形式展示，数据可以单独项目，甚至多个域名的数据可以放到不同的项目中，由不同的人（团队）负责维护。
+ 支持多域名，支持文章多层级分类，这些层级依次是：栏目、一级分类、二级分类
+ 使用文件系统组织数据，每个站点对应一个数据目录，栏目、一级分类、二级分类、文章等都是子目录。好处有三个：
    1. 分类和内容都很清晰，不论是人工还是AI都能开始解读文章内容和层次分类
    2. 无需辅助工具，直接操作文件系统就可以改变栏目等分类，即简化了数据维护上手成本，也简化了系统的设计
    3. 方便版本控制：所有的信息都是通过文件层级，文件/文件夹的名称和文本文件(yaml，md等)来组织的，diff和提交记录清晰可见，直接把网站数据放到git仓库中，不需要另外考虑备份，系统也不需要设计更新记录和恢复机制。
+ 使用扩展的 Markdown（EXMD）格式，在markdown基础功能的基础上，增加图表，时间线等可视化控件，增加分栏布局功能，使文章内容更丰富。支持单md文章方便手写简短的笔记或者备忘，也支持多md文件组成一个大文章，同时图表数据可以引用外部数据文件，降低单个文件的复制度，提高文章的可维护性，尤其是方便AI生成文章。
+ 只展示，不互动：本系统只负责将数据展示为网页，不负责用户交互，如评论、点赞、收藏等。
+ 不支持用户登录注册：本系统不负责用户登录注册，用户只能查看数据，不能进行交互。
+ 没有管理员：所有修改都通过修改网站数据文件来实现，没有管理页面


## 功能需求

### 文章层级

| 层级 | 作用 | 示例 |
|---|---|---|
| 站点 | 域名级数据目录 | `science.example.local` |
| 栏目 | 站点首页入口 | 数学、物理、自然景观 |
| 一级分类 | 栏目下的主题分组 | `01 代数`、`03 东北` |
| 二级分类 | 一级分类下的细分 | `古代`、`01 浙江省` |

### 文章组成

| 层级 | 作用 |
|---|---|
| 文章 | 最小内容单元 |
| 章节 | 文章下的主题分组 |
| 段落 | 章节下的内容单元 |
| 文本/图片/图表/表格等 | 段落下的内容元素 |

### 内容格式

- 基础格式：扩展 Markdown（EXMD），兼容标准 Markdown 语法。
- 文章模式：支持单 Markdown 文件与多 Markdown 文件两种模式。
    - 单文件模式：每个文章对应一个 Markdown 文件，用于简短的文章或备忘。
    - 多文件模式：每个文章，每个文件对应，每个文件对应一个章节，多个文件可以组成一个大文章，用于较长的文章
   - 扩展控件：支持统计卡片、卡片列表、时间线、分支图、标签芯片、树状图、图表、分栏等。
- 内容层级：文章 → 章节 → 段落 → 文本/图片/图表/表格等元素。


### 站点管理

| 需求 | 说明 |
|---|---|
| 多站点支持 | 一个数据目录下可放置多个站点，按域名映射 |
| 站点配置 | 通过 `meta.yaml` 定义站点标题、栏目、封面、标签等 |
| 独立栏目 | 每个站点可配置多个栏目，栏目下支持多级分类 |


### 页面使用

页面
- 首页：展示所有栏目，点击栏目跳转到栏目首页。
- 栏目首页：通过页签的方式展示一级分类和二级分类后的所有文章标题，点击文章标题跳转到文章详情页。
- 文章详情页：展示文章内容。
- 关于页：展示站点帮助文档，如使用说明等。

风格
- 设计：简洁、直观、扁平化、颜色属于同一色系，内容不乱。
- 支持多主题切换：提供多种预设主题，支持日夜间、护眼等风格，但要符合设计规范

### 编译与构建

- 编译工具：Python 脚本将 Markdown 源数据编译为 JSON。
- 索引生成：站点首页、栏目首页自动汇总分类与文章索引。
- 编译模式：支持全量、增量、预览模式。
