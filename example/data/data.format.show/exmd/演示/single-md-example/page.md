## 基础文本格式

Markdown 支持多种内联文本格式：

**加粗文本** 用于强调重要内容。

*斜体文本* 用于表示引用或特殊含义。

`行内代码` 用于标记代码片段或技术术语。

[外部链接](https://www.example.com) 用于跳转到外部网站。

~~删除线~~ 用于标记已废弃或修改的内容。

## 代码块

```python
def bubble_sort(arr):
    n = len(arr)
    for i in range(n):
        swapped = False
        for j in range(0, n - i - 1):
            if arr[j] > arr[j + 1]:
                arr[j], arr[j + 1] = arr[j + 1], arr[j]
                swapped = True
        if not swapped:
            break
    return arr
```
